# Steady — frontend

React + Vite web app for people with irregular income. Installable to a phone's home screen (PWA) and
works offline. Education and planning support, not regulated financial advice.

## Run it

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
npm run build      # production build in dist/ (service worker active here)
npm run preview    # serve the production build
```

To use the real AI backend, create `frontend/.env.local`:

```
VITE_API_URL=http://localhost:8000
```

Without it, the app uses local mocks in `src/mocks/` (clearly labelled in the UI). The API contract is in
[`docs/handoff/ai-api.md`](../docs/handoff/ai-api.md).

## Add to home screen

Open the deployed site (HTTPS) on a phone. Android Chrome: menu → *Install app*. iPhone Safari: Share →
*Add to Home Screen*. Icons are generated by `npm run icons`.

## Structure

| Path | What it does |
|---|---|
| `src/lib/engine.js` | All calculations: steady pay, safe weekly spend, buffer, simulator, report. Pure functions. |
| `src/lib/api.js` | Adapter for `/api/parse` and `/api/explain`, falling back to mocks. |
| `src/lib/store.jsx` | Profile state, saved to `localStorage` only. |
| `src/pages/Landing.jsx` | Introduction and disclaimer. |
| `src/pages/Planner.jsx` | Tool 1: voice/text or question form → plan, chart, analysis, advice. |
| `src/pages/Simulator.jsx` | Tool 2: what-if a source stops, with and without buffer. |
| `src/pages/Report.jsx` | Tool 3: printable, self-reported one-page income summary. |
| `src/components/Explain.jsx` | AI explanation panel (summary, meaning, three next steps). |
| `public/sw.js`, `public/manifest.webmanifest` | Offline support and install metadata. |

## How the numbers work

- **Steady pay** = 25th percentile of monthly income (lowest month if fewer than 4 months).
- **Safe weekly spend** = (steady pay − fixed costs) × 12 / 52.
- **Buffer target** = fixed costs × cover months, where cover = 2 + 4 × (coefficient of variation),
  rounded to 0.5 and clamped to 2–6.
- **Simulator**: each source continues at its median weekly level; bills leave on their due day,
  essential first, then important, then flexible. "With buffer" starts from the buffer target.
